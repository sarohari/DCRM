# Implementation task guidance

Implementation tasks translate an approved design into reviewable work and acceptance criteria. Use the S01–S08 task files as the project format.

## Required guide impact check

Every task that changes user-visible features, navigation, labels, workflows, permissions, or reports must include a **Guide impact** check. The task must update affected content in `templates/core/how_to_use.html` in the same change, or record a specific reason why the guide is unaffected. Do not mark the task complete if the assessment is missing. Remove instructions for retired controls in the same change that removes them.
