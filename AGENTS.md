# Project guidance

## Keep the in-app guide current

- For every user-visible app change to features, navigation, labels, workflows, permissions, or reports, assess its effect on `templates/core/how_to_use.html`.
- If the change affects a guide instruction, available action, role scope, or route, update the guide in the same change.
- If the guide is unaffected, record a specific no-impact reason in the task or change summary. A missing assessment does not pass completion.
- Remove instructions for retired controls in the same change that removes them.
- Apply this check to future SDD implementation task documents as well as code changes.
